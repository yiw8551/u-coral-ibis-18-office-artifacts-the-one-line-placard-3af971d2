## What it does

`main.ts` writes a single museum placard — one line, at most 180
characters — to `/output/entry.txt`. The placard recasts an ordinary
office stapler as an ancient artifact: a ritual binding device that
sealed the covenants of a department that no longer exists, found in
the bottom drawer, still loaded, and gifted by Accounts Payable.

## Run

```sh
node main.ts
```

Requires Node 22 or later. The output is deterministic: every run
writes the same line.
